# 🏎️ Formula 1 Racing Intelligence Dashboard (2010–2026)

## 📌 Project Overview
This project analyzes Formula 1 racing data using Tableau to explore driver performance, team achievements, race results, circuits, and pit-stop efficiency.

The interactive dashboards and story visualizations help users explore racing performance patterns and compare available metrics.

## 🎯 Objectives
- Analyze driver performance using championship points.
- Compare constructor and team performance.
- Explore race results across seasons.
- Examine circuit-related racing data.
- Analyze grid position versus finishing position.
- Explore tyre compound distribution.
- Investigate driver retirements (DNF).
- Examine pit-stop performance.

## 🛠️ Tools & Technologies
- Tableau
- Microsoft Excel
- Data Visualization
- Exploratory Data Analysis

## 📊 Key Dashboards
### 1. Formula 1 Racing Analytics
Provides an overview of Formula 1 racing performance through interactive visualizations.

### 2. Driver & Team Analytics
Explores driver performance, team metrics, tyre compounds, retirements, grid-versus-finish positions, and pit-stop data.

## 📁 Project Files
- `F1_Racing_Analytics.twbx` — Packaged Tableau workbook containing the dashboard and story.
- `F1 Racing Project Dataset.xlsx` — Dataset used for the analysis.
- `project phase 1.twb` — Earlier Tableau workbook version.

## 🚀 How to Use
1. Download `F1_Racing_Analytics.twbx` from this repository.
2. Open it using Tableau Desktop.
3. Explore the dashboards and Story Points.
4. Use available filters and interactive charts to investigate the data.
